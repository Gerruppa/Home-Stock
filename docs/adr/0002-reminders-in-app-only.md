# Reminders only inside the app

Running Low, Expiring Soon and Expired Products are shown on the Start tab when the app is opened; there are no Windows notifications and no background process or scheduled task. A background notifier is a sizeable separate piece (autostart, a tray process or Task Scheduler, notification permissions) for a single-user app that is opened when the user checks the cupboards anyway. It can be added later without changing the model.
